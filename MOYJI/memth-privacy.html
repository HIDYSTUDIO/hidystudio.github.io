Memth 개인정보처리방침

시행일 2026년 11월 12일

HIDY STUDIO는 Windows 및 Android용 Memth 앱에서 정보를 다음과 같이 처리합니다.

1. 앱에서 처리하는 정보와 목적

Memth는 사용자가 작성한 메모, 투두와 완료 기록, 일정, 그룹, 사진, 드로잉과 앱 설정을 기기에 저장합니다. 이 정보는 기록 열람·편집, 검색, 알림, 백업 및 복원에 사용됩니다. 사진은 사용자가 선택한 파일을 가져옵니다. 기본 기능은 별도의 Memth 계정 없이 사용할 수 있습니다.

Android 앱은 사용자가 허용한 권한에 따라 기기 캘린더에서 일정과 캘린더 정보를 읽고, 사용자가 저장 대상으로 선택하거나 자동 저장 대상으로 설정된 캘린더에 일정을 기록합니다. Google 계정과 연동된 기기 캘린더에 저장한 일정은 해당 계정의 동기화 설정에 따라 Google에 반영됩니다. 알림, 진동과 정확한 알람 권한은 사용자가 지정한 일정과 투두의 알림에 사용됩니다.

2. Windows 앱의 Google 캘린더 연결

  • 인증. Google 계정 연결을 선택하면 기본 브라우저에서 Google 로그인과 권한 동의가 진행됩니다. Memth는 Google 비밀번호를 받지 않습니다. Windows 앱은 Google이 발급한 인증 정보를 캘린더 요청과 연결 유지에 사용합니다. 갱신 토큰은 Windows의 사용자별 데이터 보호 기능으로 암호화해 기기에 저장합니다.
  • 일정 읽기. Windows 앱은 Memth 캘린더를 찾고 외부 캘린더를 선택할 수 있도록 캘린더 ID, 이름, 표시 색상, 접근 권한 등 목록 정보를 확인합니다. 해당 기능에 필요한 권한과 사용자의 선택에 따라 일정 식별자, 제목, 시작·종료 시간, 시간대, 종일 여부, 장소, 설명과 반복 일정의 발생 내역을 가져와 달력에 표시합니다.
  • 일정 쓰기. 동기화 대상으로 설정한 일정의 제목, 시작·종료 시간, 시간대, 종일 여부, 장소, 설명, 반복 규칙과 알림 설정을 Google 캘린더에 보냅니다. 일정의 중복 저장을 줄이고 변경분을 반영하기 위해 일정 식별자와 변경 여부를 확인하는 값도 사용합니다. 자동 동기화를 켜면 Windows 앱이 실행 중일 때 이 처리가 백그라운드에서도 이루어집니다.
  • 전송 범위. 캘린더 요청은 Windows 앱과 Google 서비스 사이에서 암호화된 연결로 처리됩니다. Memth 운영 서버를 거치지 않으며, 메모 본문, 첨부 사진, 드로잉, 투두와 완료 기록은 Google 캘린더 동기화로 전송하지 않습니다.

Memth는 Google API를 통해 받은 정보를 앱에 표시된 캘린더 기능을 제공하는 데 사용합니다. 이 정보를 광고, 판매 또는 이용자 프로파일링에 사용하지 않습니다. Google API를 통해 받은 정보의 사용과 이전은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. Google API 서비스 사용자 데이터 정책

Google 계정과 Google 캘린더에 저장된 정보의 처리는 Google의 정책이 적용됩니다. Google 개인정보처리방침

3. 보관 및 삭제

  • 기기 기록은 사용자가 삭제할 때까지 기기에 보관됩니다. 휴지통이 적용되는 기록은 앱에서 복원하거나 영구 삭제할 수 있습니다.
  • Windows Google 연결 정보와 일정 캐시는 연결을 유지하고 일정을 표시하는 데 사용합니다. 캘린더 설정에서 연결 해제를 선택하면 기기에 저장한 Google 연결 정보와 일정 캐시가 삭제됩니다. Google 계정에서도 Memth의 접근 권한을 철회할 수 있습니다. 이미 Google에 저장된 일정은 Google 캘린더에서 직접 관리할 수 있습니다. Google 계정의 타사 연결 관리
  • 백업 파일은 사용자가 지정한 위치에 저장되며, 앱의 원본 기록이나 연결 정보를 삭제한 후에도 그 위치에 남을 수 있습니다. 복원용 ZIP에는 숨긴 항목과 휴지통 기록이 포함될 수 있습니다. 클라우드 저장 위치를 선택하거나 파일을 공유하면 해당 서비스 또는 수신자가 파일을 보관할 수 있습니다.
  • 고객지원 문의를 이메일로 보내면 발신 주소와 문의 내용을 답변 및 처리에 사용합니다. 문의 기록은 문의 처리에 필요한 기간 동안 보관하고, 처리가 끝나면 삭제합니다. 법령에서 별도 보관을 요구하는 경우에는 해당 기간 동안 보관합니다.

4. 이용자 권리와 문의

앱에 저장된 기록은 앱에서 열람·수정·삭제할 수 있습니다. 이용자 및 법정대리인은 아래 연락처로 개인정보의 열람, 정정·삭제, 처리정지 등 관계 법령에 따른 권리 행사를 요청할 수 있습니다.
