# HIDY STUDIO

Independent Game & Software Development Studio

HIDY STUDIO는 게임과 소프트웨어를 만드는 1인 개발 스튜디오입니다.

이 저장소 하나에 **메인 홈페이지, HIDY GAMES, MOYJI** 웹사이트의 모든 정적 파일을 관리합니다.

## 배포

GitHub 저장소 `HIDYSTUDIO/hidystudio.github.io`에서 `Settings → Pages → Deploy from a branch → main → /(root)`로 배포합니다.

**기존의 HidyGames / MOYJI 저장소를 삭제하기 전** `MIGRATION_GUIDE.md`를 읽고 두 저장소의 Pages 게시를 중단한 후 새 경로를 검증하세요. 기존 저장소는 ZIP 백업을 따로 보관해 주세요.
