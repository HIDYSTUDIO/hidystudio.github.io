# HIDY STUDIO

**Independent Game & Software Development Studio**

## About

HIDY STUDIO는 다양한 장르의 게임과 일상에 도움이 되는 소프트웨어를 기획하고 개발합니다.

작은 호기심과 아이디어에서 출발해 직접 만들고, 테스트하고, 다듬는 과정을 이어가고 있습니다. 완성된 결과물뿐 아니라 새로운 시도와 개발 과정도 함께 기록합니다.

현재 두 가지 브랜드를 운영하고 있습니다.
