# HIDY STUDIO

**Independent Game & Software Development Studio**

작은 아이디어를 게임과 소프트웨어로 만들어가는 독립 개발 스튜디오입니다.

HIDY STUDIO는 게임 개발 브랜드 **HIDY GAMES**와 기록·소프트웨어 프로젝트 **MOYJI**를 운영합니다.

## Our Projects

### 🎮 HIDY GAMES

**Play. Create. Explore More.**

다양한 장르의 게임을 기획하고 개발합니다.

PC와 모바일 플랫폼을 중심으로 새로운 게임 경험을 만들고 있습니다.

**Projects**
- Gacha Capsule Smasher — PC Action Game
- GRAVTILE — Android Puzzle Game
- More projects in development

**[Visit HIDY GAMES](https://hidystudio.github.io/HidyGames/)**

### 📝 MOYJI

**뭐였지? 여기 있지.**

*모아두고, 다시 찾는 기록들..*

일상 속 다양한 정보와 기록을 정리하고, 필요할 때 다시 찾을 수 있도록 돕는 소프트웨어 프로젝트입니다.

메모, 일정, 할 일 등 일상에 필요한 기능을 직관적이고 편리한 프로그램으로 개발합니다.

**Projects**
- Memth — Memo, Todo & Calendar
- More applications in development

**[Visit MOYJI](https://hidystudio.github.io/MOYJI/)**

HIDY STUDIO is an independent development studio creating games and practical software.
